# AFTERTIDE: The Meridian Archive

**AFTERTIDE** 是一款原创的单人海底远征策略游戏。海面沉寂 43 年后，玩家接管最后一艘深潜船，在七次出航内修复 Meridian 信标，并决定是否唤醒旧城档案中的意识。

## 已实现的垂直切片（待 Godot 引擎运行验收）

- 1280×720 桌面版界面：远征地图、船体状态、氧气、士气、信标、库存、船员档案和记忆档案。
- 三处潜水区域，风险与潜在收益不同。
- 七日行动窗口；每次潜水都会消耗氧气、船体和士气。
- 每个地点有两种处置方式，改变资源、船员状态和叙事结果。
- 一次船体整备升级，以及多个结局状态。
- 原创世界观、角色、文案和程序绘制界面；未使用第三方游戏素材或代码。

这是一个首版 vertical slice 项目，当前不是完整商业发行版。Godot 运行时尚未验收；音效、音乐、正式美术、更多任务、存档和发行包还未制作。

## 运行

需要 Godot 4.x。用 Godot 项目管理器导入本目录，或从命令行运行：

```sh
godot --path .
```

只用鼠标操作。地图上点选地点，再点 **DIVE TO SITE**；事件页选择处置方案。每次回船后会补给一部分氧气。船体升级每趟远征只能买一次，需要 3 个 Scrap。

## 原创定位

- 世界：沉没的 Meridian 城、最后的深潜船与信号档案。
- 核心张力：短期生存资源与追寻真相之间的取舍。
- 结构：基地状态管理 + 区域选择 + 事件抉择 + 结局回报。
- 独立身份：项目文件、标题、文案中没有工作室或雇主信息；发布时继续使用独立创作者署名。
