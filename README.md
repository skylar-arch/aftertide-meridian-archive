# AFTERTIDE: The Meridian Archive

A standalone single-player expedition strategy story set in a drowned city.

> The world went under. The lights didn't.

Lead a salvage crew into the Meridian, manage oxygen and hull integrity, and choose what to bring back from the archive. Seven watches remain before the signal goes dark.

## Prototype

This Godot 4 project is an early vertical slice. It currently includes a title screen, expedition chart, crew and archive panels, three dive sites, resource management, branching event decisions, and ending states. It is a native game project; no HTML game code is used.

Runtime validation: opened and ran with Godot 4.7.2 in headless mode. A desktop export and external downloadable build are not included yet.

## Run

Open this folder in Godot 4.x, or run:

```sh
godot --path .
```

Mouse controls: choose a dive site on the chart, dispatch, then select how the crew handles each event. Upgrade the hull between dives when you have enough scrap.
